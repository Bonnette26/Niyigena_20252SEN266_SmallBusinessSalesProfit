\# Phase II – Data Source Documentation



\## 1. Dataset Name

Online Retail Dataset



\## 2. Data Source

UCI Machine Learning Repository



Official link: https://archive.ics.uci.edu/dataset/352/online+retail



\## 3. Dataset Description

The Online Retail dataset contains transactions from a UK-based online retail business. The records cover the period from 1 December 2010 to 9 December 2011.



\## 4. Dataset Size

\- Number of records: 541,909

\- Dataset file: Online Retail.xlsx

\- File size: Approximately 22.6 MB

\- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)



\## 5. Main Attributes

1\. InvoiceNo – Unique transaction number.

2\. StockCode – Unique product code.

3\. Description – Product name.

4\. Quantity – Number of items purchased.

5\. InvoiceDate – Date and time of the transaction.

6\. UnitPrice – Selling price per item.

7\. CustomerID – Unique customer identifier.

8\. Country – Customer's country.



\## 6. Relevance to the Project

This dataset is relevant because it contains real retail transaction records. It can support the design of a Small Business Sales and Profit Tracking System, especially sales, products, customers, and transaction details.



\## 7. Dataset Limitations

The dataset does not provide product purchase costs, supplier records, or operating expenses. Therefore, it cannot independently provide complete business profit calculations. These additional records must be obtained from a separate authentic source or collected separately.
